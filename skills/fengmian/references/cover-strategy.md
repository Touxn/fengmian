# High-clarity creator cover strategy

Use this reference when turning a video, article, outline, or long title into a cover proposition.

## Strategic objective

Treat the cover as a compressed click contract. Let it answer three questions within one glance:

1. What is this about?
2. What useful change can the viewer expect?
3. Why is it worth attention now?

Keep one meaningful answer inside the video or article. The hidden item can be the method, list, reason, comparison, or final result.

Apply the useful information architecture associated with high-performing creator covers: strong topic recognition, one promise, one visual metaphor, one creator role, and one information gap. Preserve the user's own face, natural expression, and long-term brand system.

## Publishing title and cover phrase

Keep these as two coordinated layers.

### Publishing title

Use the publishing title to carry the complete proposition:

- Precise topic or product
- Audience
- Scope, duration, or result
- Test method or proof
- Version or timing when relevant

### Cover phrase

Use the cover phrase as the fast visual index:

- Product or category name
- One value word or result signal

Preferred patterns:

- `[产品名] + 全解`
- `[产品名] + 实测`
- `[品类] + 大全`
- `AI + [具体任务]`
- `[能力] + 实战`
- `[能力] + 新玩法`
- `[结果] + 全流程`

Keep the phrase short enough to dominate the thumbnail. Use 2 to 8 Chinese characters when possible. Product names and versions can extend the count.

## Content extraction

Extract these fields from the source content before ideating:

| Field | Question |
| --- | --- |
| Topic anchor | Which product, task, event, or concept identifies the content? |
| Target viewer | Who benefits and what is their current level? |
| Transformation | What changes after viewing or reading? |
| Evidence | What makes the promise credible? |
| Dominant value | Complete, deep, easy, fast, practical, new, portable, tested, or outcome-focused? |
| Emotional tone | Control, relief, curiosity, surprise, urgency, confidence, or empathy? |
| Information gap | Which single answer should remain unrevealed? |
| Visual result | Which object or scene makes the change visible? |
| Dominant prop | Which single oversized object can carry the topic? |
| Background world | Which quiet place or color field supports the topic? |

Choose one dominant value. Move secondary benefits into the publishing title or content description.

## Three-route proposal

Produce alternatives only when requested, using the requested count (three if unspecified). For a creation request with delegated creative choices, choose one route internally and continue to generation.

### Route A, mastery

- Promise completeness, understanding, or control
- Use guide, cockpit, map, manual, compass, or teaching metaphors
- Suitable for tutorials, explainers, and foundational topics

### Route B, practical outcome

- Promise a visible task result or easier workflow
- Use toolbox, production line, before-and-after result, device, or finished artifact
- Suitable for office, coding, editing, and automation topics

### Route C, curiosity or upgrade

- Promise a new capability, unexpected result, or important change
- Use reveal, layered structure, unlocked mode, launch, or transformation metaphors
- Suitable for product updates, tests, trends, and comparisons

For each route, state:

- Cover phrase
- Click promise
- Visual metaphor
- Four-signal alignment: headline, prop, action, background
- Person role and gesture
- Person action, contact point, gaze target, and scene consequence
- Dominant object
- Proof element
- Main risk

Recommend the route that best balances clarity, credibility, distinctiveness, and brand continuity.

## Visual metaphor selection

Translate an abstract capability into a physical relationship.

| Content pattern | Useful metaphor |
| --- | --- |
| Complete tutorial | Manual, map, cockpit, control panel, guided path |
| Tool collection | Shelf, toolbox, curated tray, library |
| Workflow | Production line, connected stations, transformation path |
| Reusable process | Binder, recipe book, template kit, stamped standard |
| Progressive loading | Layered drawers, stacked reveal, spotlighted tiers |
| New capability | Unlock, upgraded module, launch, expanded workspace |
| Comparison | Two clear objects with one visible decision criterion |
| Business outcome | Finished product, verified dashboard, delivery box |

Use a metaphor only when it explains the content. Reject imagery selected solely for spectacle.

## Person role

Give the person one clear role:

- Guide for tutorials
- Tester for reviews
- Operator for workflows
- Curator for collections
- Builder for practical projects
- Witness for surprising results
- Analyst for trends or serious topics

Use `person-integration.md` to turn the role into a physical action. Connect the person to the main object through contact, gaze, shared light, perspective, depth, and a visible scene consequence. Keep the face natural by default. Put energy into body angle, hand movement, costume, prop, and scene direction.

## Evidence and claim discipline

Use proof when the cover or publishing title makes a strong claim.

Valid proof can include:

- Actual test result
- Finished artifact
- Duration or number of steps
- Version number
- Before-and-after comparison
- Reproducible case
- Source document or dataset

Avoid `最全`, `第一`, `独家`, `99%`, `终极`, guaranteed income, and guaranteed performance without evidence. When proof is weak, describe only what the source establishes, such as `方法介绍` or `阅读笔记`. Use `实测`, `完整教程`, or `从零实战` only when actual supplied or verified evidence supports that specific claim.

## Intake template

The user can provide a compact brief:

```text
主要内容｜我讲什么，帮助谁完成什么，最重要的结论是什么
发布标题｜完整标题或暂定标题
涉及对象｜产品、版本、平台、人物、事件或概念
可信依据｜实测、案例、时长、数据、截图或成果
相关图标｜附文件、附链接、需要搜索或需要生成意象图标
人物要求｜表情、动作、服装、相似度与禁止项
输出比例｜3:4、4:3、16:9或全尺寸
必须出现｜指定文字、对象、数字或结果物
禁止出现｜夸张词、颜色、元素或敏感承诺
```

When only the title and main content are supplied, infer routine creative details and complete the requested cover. Present alternatives only when requested; do not ask the user to design the layout, choose colors, or invent a metaphor.

## Selection test

Score each route from 1 to 5:

- One-second topic recognition
- Strength of one click promise
- Fidelity to the source content
- Simplicity of the visual sentence
- Credibility of the claim
- Fit with the user's portrait and brand
- Strength of person-scene integration
- Adaptability across requested ratios

Select the route with the highest total. Reject any route that scores below 4 for topic recognition or source fidelity.

Also reject a route that scores below 4 for creator-cover genre fit, background quietness, or action readability at 10 percent size.
