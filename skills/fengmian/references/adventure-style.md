# Optional adventure and journey style

Use this reference when an adventure or journey concept has been selected. Treat the journey as one available visual relationship, and follow the user's content, approved wording, and protected regions.

A task path, milestones, and destination can make progress tangible. The finished output may become terrain, a stage, or a destination when that metaphor clarifies the subject. Keep the main result recognizable at the intended display size.

A person may guide, witness, or actively operate within the scene. Physical contact is optional; when depicted, check anatomy, support, and consistent perspective. Without a supplied portrait, use the requested subject, object, or setting without inventing an identity.

Choose palette, scale, title position, and number of elements according to the promise and evidence. Do not force a title-first hierarchy, fixed proportions, a vehicle, or a bright natural world. Protect exact wording. Use a compositing workflow only when current tool instructions permit and the user has authorized the method.

For a new composition, establish the main focal point, build a clear journey, and inspect both full size and intended thumbnail size. For local edits, start from the accepted target and follow `revision-control.md`; do not rebuild protected content. An output that cannot show the promise clearly needs revision, but visual inspection alone does not establish click performance.
