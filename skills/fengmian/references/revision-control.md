# Revision control and identity protection

Read for a local edit, face correction, or additional ratio. Resolve the target, permitted changes, protected content, and exact wording from the current request. A selected concept remains selected for local revisions and ratio extensions.

- Keep candidate, delivered, accepted, and rejected states distinct for each ratio. A generated image does not become approved automatically.
- Use the user-selected cover as the edit target. For a title-only edit, preserve identity, scene, pose, clothing, other wording, and all other approved details. For a face correction, preserve the approved scene and use the supplied original portrait as identity authority.
- Use actual supported region controls or retained layers when available. If the tool rerenders the whole canvas, specify the edit target, identity reference, permitted region, and protected features. Do not claim a mask or pixel lock that the tool does not provide.
- Inspect the candidate and accepted baseline at equal scale. When a face exists, check identity at useful full size and against the original portrait. If a protected feature drifts, return to the accepted baseline and use a better supported method. Stop repeating an ineffective repair chain and disclose material limitations.
- For strict unchanged requests, use a supported read-only image comparison where available. Visual similarity, identical pixels, and user approval are distinct outcomes. Never claim pixel identity without measuring it.
- Adapt an additional ratio through repositioning, expansion, or a new composition. Crop only when permitted and important wording, identity, evidence, and meaning survive. Check each ratio independently; do not alter unrequested versions.
- Preserve original assets and a concise revision note with inputs, exact text, per-ratio status, changed and protected regions, and checks performed. Do not publish or generate extra variants without the requested scope.
