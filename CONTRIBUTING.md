# Contributing

Contributions should improve a repeatable cover-design decision, validation step, or portability boundary.

Before opening a change:

1. Keep `SKILL.md` concise and route conditional detail to the relevant reference.
2. Do not add portraits, private screenshots, client work, local absolute paths, API keys, proprietary fonts, or unlicensed logos.
3. Keep adventure styling optional and choose scenes from the source content.
4. Preserve exact user-approved text, protected regions, and independently checked aspect ratios.
5. Run `python3 -m unittest discover -s tests -v`.
6. If scripts change, test observable output rather than matching wording alone.

Examples should be fictional, brand-neutral, and licensed for redistribution. Record their status in `ASSET-LICENSES.md`.
